# Портфолио Frontend Developer

## 📌 О проекте

Персональное портфолио-резюме фронтенд-разработчика. Одностраничный сайт, демонстрирующий навыки, проекты и опыт работы.

**Технологии:** HTML5, CSS3, Vanilla JavaScript (без фреймворков)

## ✨ Особенности

### 🎨 Дизайн

- Тёмная тема с акцентным синим цветом (#3b82f6) и фиолетовыми переходами (#8b5cf6)
- Адаптивная вёрстка (desktop → tablet → mobile)
- Шрифты: Inter (текст) + JetBrains Mono (код)
- Иконки: Font Awesome 6
- Glassmorphism на карточках контактов и образования

### 🎬 Анимации

- **Matrix Rain** — падающие символы на фоне hero-секции (синие с фиолетовыми акцентами)
- **Typing Effect** — текст "Frontend Developer" печатается при появлении в viewport
- **Scroll Animations** — секции плавно появляются при прокрутке (Intersection Observer)
- **Canvas Lightning** — реалистичные электрические разряды по рамке карточек проектов (Midpoint Displacement, ветвление, затухание)
- **Spotlight Hover** — неоновое свечение следует за курсором на карточках навыков
- **AI Decoding Text** — текст навыков "расшифровывается" при наведении (хакерский эффект)
- **AI Typing Cursor** — мигающий курсор █ при печати абзацев "О себе"
- **3D Tilt** — карточка образования наклоняется за курсором с parallax-эффектом
- **Stagger Animation** — каскадное появление карточек контактов
- **Hover-эффекты** на карточках проектов и навыков

### 📱 Адаптивность

- Desktop: 1024px+ (3 колонки / auto-fit)
- Tablet: 768-1024px (2 колонки)
- Mobile: < 768px (1 колонка)

## 🚀 Оптимизации

### Производительность

- **Matrix Rain** использует `requestAnimationFrame` вместо `setInterval`
- Матрица останавливается, когда hero-секция не видна (Intersection Observer)
- Scroll-события с throttle (100ms) для прогресс-бара
- CSS-анимации вместо JS (GPU-ускорение)
- Canvas-молнии останавливаются при уходе мыши и возобновляются при возврате

### Размер

- ~290 строк HTML
- ~1070 строк CSS
- ~590 строк JS
- Без зависимостей (CDN только для шрифтов и иконок)

## 🔧 Установка

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Для локальной разработки: `npx http-server`

## 📝 Кастомизация

### Изменить фото

Замените `images/avatar.png` на своё фото

### Обновить навыки

Редактируйте список в `index.html` (секция `.skill-list`)

### Настроить цвета

В `css/style.css` измените CSS-переменные:
```css
:root {
	--color-accent: #3b82f6;
	--color-bg: #0f172a;
	/* ... */
}
```

### Настроить молнии

В `js/main.js` в функции `initLightning()`:
- `Math.random() < 0.25` — частота появления молний
- `decay: 0.04 + Math.random() * 0.07` — скорость затухания
- `bolts.length < 3` — максимум активных разрядов
