## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox/Grid, CSS-анимации, transitions
- **Font Awesome** (CDN) — иконки
- **Google Fonts** — Inter + JetBrains Mono (для кода)
- **Адаптивность** — mobile-first, 3 брейкпоинта
- **Без JS-фреймворков** — чистый CSS для анимаций

## Пошаговая реализация

### Шаг 1: HTML-структура
- Hero-секция с фото + имя + должность + CTA-кнопки
- Секции: О себе, Навыки, Опыт, Проекты, Образование, Контакты
- Семантические теги: `<header>`, `<section>`, `<footer>`

### Шаг 2: CSS-переменные и сброс
- Цвета: тёмный фон `#0f172a`, акцент `#3b82f6`, текст `#e2e8f0`
- Шрифты: Inter для текста, JetBrains Mono для кода
- Reset/normalize

### Шаг 3: Hero-секция
- Flexbox/Grid центрирование
- Фото: круглое, 150×150px, с анимацией появления
- Имя + должность крупным шрифтом
- CTA-кнопки с hover-эффектами
- Ссылки на соцсети с иконками

### Шаг 4: Секция навыков
- Grid-сетка (3 колонки на десктопе, 2 на планшете, 1 на мобильном)
- Карточки навыков с иконками
- Прогресс-бары или теги для каждого навыка

### Шаг 5: Секция проектов
- Карточки проектов в grid (3 колонки)
- Каждая карточка: скриншот, название, описание, стек, ссылки
- Hover-эффекты на карточках

### Шаг 6: Остальные секции
- О себе: текст + ключевые факты
- Опыт: timeline-стиль
- Образование: карточки
- Контакты: email + телефон + соцсети

### Шаг 7: Адаптивность
- `@media (max-width: 1024px)` — 2 колонки
- `@media (max-width: 768px)` — 1 колонка, мобильное меню
- `@media (max-width: 480px)` — компактный режим

### Шаг 8: Анимации
- Fade-in при скролле (CSS `@keyframes`)
- Hover-эффекты на кнопках и карточках
- Плавная прокрутка к секциям
